# Larix Music Reactive Lights

Home Assistant Add-on that receives an audio stream from **Larix Broadcaster** and makes your lights dance to the music.

Includes a live **Watchdog GUI** (Ingress panel) showing connection status, live bass/mid/high/amplitude meters, beat detection, active profile, and a recent-events log.

See [DOCS.md](DOCS.md) for full documentation.
